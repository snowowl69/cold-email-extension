# Extension Icons

Place the following icon files in this directory:

- `icon16.png` — 16×16 px (toolbar icon)
- `icon48.png` — 48×48 px (extensions page)
- `icon128.png` — 128×128 px (Chrome Web Store / install dialog)

## Quick Option

You can generate simple icons using any image editor or online tool.
A gradient purple-to-cyan envelope/mail icon works well with the extension's theme.

The extension will still load and function without these icons — Chrome uses a default puzzle-piece icon instead.
